# @accretion/react

React wrappers for Accretion UI web components.

## Installation

```bash
npm install @accretion/react @accretion/core
```

## Usage

```tsx
import { AccretionButton } from '@accretion/react';

export function Example() {
  return <AccretionButton>Click Me</AccretionButton>;
}
```

## Peer dependencies

- `react` `^18.2.0 || ^19.0.0`
- `react-dom` `^18.2.0 || ^19.0.0`
- `@accretion/core` `^0.1.0`
